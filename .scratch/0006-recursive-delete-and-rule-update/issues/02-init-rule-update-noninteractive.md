# 02 — init 显式规则更新：检测、追加、备份、非交互（cli）

**What to build:** 存量用户运行 `auto-guard init`（非交互 flag 显式选择更新或跳过）时，安装器对比出厂默认与本地配置根的两层规则文件，找出"出厂有、本地无"的模式条目，非交互接受时按「幂等追加 + 去重 + 写前 `*.auto-guard.bak` 备份」写入 defaults.json 与 rules.json 两层；拒绝时两份文件一字不动；重复运行结果一致；`remove` 卸载语义不受影响（ADR-0013）。运行时加载行为不改动。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 非交互接受：出厂有而本地两层皆无的模式条目被追加进两层文件；本地已有条目不重复、不改动位置
- [ ] 用户自定义条目与既有条目逐字保留（含顺序）
- [ ] 写盘前 `*.auto-guard.bak` 备份生成；拒绝/跳过路径不产生任何写入
- [ ] 幂等：连续两次运行，第二次为 no-op
- [ ] 无本地缺失时报告"已是最新"且不写盘
- [ ] 临时配置根端到端验证：安装器测试先例（写文件、备份、幂等、卸载断言）扩展同族用例
