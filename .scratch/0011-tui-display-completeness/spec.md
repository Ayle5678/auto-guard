# 0011 — Guard TUI 显示完整性与信息架构（display-completeness）

## Problem Statement

用户验收 0010 后的两点不满 + 排查中发现的第三点：

1. **多行输出显示不完整**（`guard stats`、`guard recent` 等）。排查确认是两条独立丢失路径叠加：
   - **横向**：输出面板对超宽行静默截断（无省略号、无换行）。`guard recent` 的定宽表约 89 列（时间+工具+结果+层级+命令），在 ~53 列面板里「层级」列整列不可见、结果列切半（`allow`→`all`）；所有管理命令的 `❯` 回执行被内部注入的 `--config-root <绝对路径>` 顶爆；`set show-key`/`examine status`/`guard status` 的绝对路径、`optimize list` 长规则行、80 列终端下的日志屏与安装预览同理。
   - **纵向**：回执贴底只显示最后一屏（视口 = 终端高−5），而四个列表屏 `↑↓` 被动作光标占用、PgUp/PgDn/g/G 未绑定——面板滚动指示符（↑/┃/↓）会声称"还有内容"但按什么都不响应。
2. **命令没有放在合适的位置**：set 屏 9 个动作无结构平铺，「界面语言」（偏好）被夹在 API 端点组和历史层之间，视觉上落在"密钥/API 设置"区中间。
3. **帮助页整体超屏**：46 行内容无条件输出且整屏不响应按键，24 行终端永远看不到最下面 25 行（审计/优化/密钥三个命令组 + 尾行）；命令表按 38% 右栏预算宽度，长命令签名（`init [--host …] […]`）在 80 列终端被切。

## Solution

一套机制两处复用：**渲染期折行**（消灭一切横向丢失）+ **输出面板滚动键**（消灭纵向丢失），再把帮助页纳入同一机制；回执改为记录用户视角 argv；set 屏动作小节分组。内容完整性原则：**只折行不静默截断，超一屏必可滚**。

## User Stories

1. 作为 TUI 用户，我想让 `guard recent` 的每一列（含层级/来源列）都可见，这样我能知道每条裁决出自哪一层。
2. 作为 TUI 用户，我想让超宽的输出行折行显示而不是被切掉行尾，这样任何命令的输出都不会静默丢失内容。
3. 作为 TUI 用户，我想让回执行只显示我输入的命令，这样内部注入的 `--config-root` 路径不再挤爆标题行。
4. 作为 TUI 用户，我想用 PgUp/PgDn/g/G 滚动列表屏的输出面板，这样超出视口的 `guard recent 30` 头部内容可以回看。
5. 作为 TUI 用户，我想让新回执继续自动贴底，这样跑完命令不用手动滚动就能看到结果尾部。
6. 作为 TUI 用户，我想在窄窗口（40×12）下也能滚看完整输出，这样最小窗口纪律不牺牲内容完整性。
7. 作为 TUI 用户，我想让安装屏的 init 预览和 `list` 输出同样折行可滚，这样长 diff 行不丢内容。
8. 作为 TUI 用户，我想让日志屏的流水行在 80 列终端折行而不是截断，这样历史记录完整可读。
9. 作为 TUI 用户，我想让 set 屏动作按 密钥/API 端点/偏好/维护 分组并带小节标题，这样我能按意图定位动作而不是在 9 行混排里找。
10. 作为 TUI 用户，我想让「界面语言」出现在偏好组里，这样它不再看起来像密钥配置的一部分。
11. 作为 TUI 用户，我想让组标题行不可选中、光标自动跳过，这样方向键不会停在无意义的分隔行上。
12. 作为 TUI 用户，我想让帮助页可以滚动，这样 24 行终端也能看到全部键位表和命令映射。
13. 作为 TUI 用户，我想让帮助页长命令签名折行到全宽，这样 `init […]` 一类长参数说明不再被右栏宽度切掉。
14. 作为 TUI 用户，我想让帮助页键位表包含新增的滚动键，这样键位文档与实际行为 100% 一致（Round 9 Q7 的纪律）。
15. 作为 TUI 用户，我想让输出面板的滚动指示符真实可用，这样它显示"还有内容"时按键必有回响。
16. 作为 TUI 用户，我想让 `r` 刷新后面板回到贴底，这样刷新后看到的仍是最新输出。
17. 作为 TUI 用户，我想让 resize（改窗口宽度）后折行重新适配新宽度，这样改窗口大小不会留下错版内容。
18. 作为 TUI 用户，我想让 footer 提示滚动键的存在，这样我能发现滚动能力而不必读帮助页。
19. 作为双语文档读者，我想让 usage.md 的键位与交互描述同步这一轮变化，这样文档不撒谎。
20. 作为维护者，我想让这一切保持纯函数渲染 + 无头断言可测，这样 UI 回归不需要真终端。

## Implementation Decisions

- **范围**：只动 `packages/tui`（渲染、路由、动作层的回执构造）+ 测试 + 文档；core/cli 零改动；零新依赖。ADR-0014 全部结论（零依赖、纯渲染、动作走 `runCli` 单一事实源、退出纪律）继续有效，**无新 ADR**（与 0010 同款结论）；设计推理见 `docs/grill-log.md` Round 10。
- **渲染期折行**：输出面板（四个列表屏、安装屏预览、日志屏）的可见内容在 render 路径用既有 `wrapToWidth`（CJK 感知）折行——与状态面板/总览卡同款策略，消灭"同屏两套截断策略"的违和。视图状态（`views[screen]`）继续只存**原始行 + offset**，折行发生在 slice 之前：先折行得到总行数，再 clamp offset、再切片——resize 自动重排，`run-done` 的贴底大 offset 语义不变。
- **滚动键分配**：列表屏与帮助屏 `PgUp`/`PgDn` 翻页、`g`/`G` 首/尾滚输出面板（帮助屏滚全文），`↑↓/jk` 保持动作光标；日志屏键位不变。offset 的 reduce 期滚动用原始行数近似，渲染期 clamp 到折行后总行数兜底（有效性由 render 保证，不要求 reduce 精确）。
- **回执记录用户视角 argv**：`execRun` 产生的回执记录 `run.argv`（用户输入/动作语义），注入 `--config-root` 只存在于实际执行调用。footer、日志屏、输出面板三个显示通道同时受益，单一修改点；动作语义（ADR-0014 决定 2）不动。
- **set 屏小节分组**：动作模型加非选中组标题行（密钥 → API 端点 → 偏好 → 维护），光标移动跳过标题行；选中映射（Enter/Space）按可选中项计算。语言归偏好组、历史层随迁、重载说明殿后。CLI 映射文案（帮助页 COMMAND_MAP）不变——CLI 侧本就是一个 `set` 组。
- **帮助页重排**：命令表改全宽预算并折行；整页纳入滚动体系；键位表补 PgUp/PgDn（及 g/G 在帮助屏的语义）。
- **footer 提示**：列表屏/帮助屏 hint 增加滚动键（如 `PgUp/PgDn 滚动`）；宽度不足时 `footerBar` 既有截断优雅降级，不做响应式特判。
- **边界（不动）**：core、cli 零改动；`exitAfterBusies` 死字段等无关清理不做；鼠标/主题/实时裁决流维持 0009 非目标；统一 CLI `set set-key` 缺口维持 0009 记录；autoload 语义（不写回执）不变。

## Testing Decisions

- **只测外部行为**：断言 `render(state)` 的可见输出与 `reduce(state, event)` 的状态迁移，不测内部函数调用关系。
- **Seam**：复用现有最高 seam——纯函数 `render`/`reduce` 的无头断言 + `execRun` 回执构造断言，**零新 seam**。Prior art：`app.spec.ts` 的 `brand + chrome rendering`、`notice (SPEC 0010)` 块、`autoload` 回归断言；`kit.spec.ts` 的面板/滚动断言。
- **关键断言**（对应验收）：
  - 超宽行折行后输出面板包含行尾内容（如 `guard recent` 行的 `[cache]` 层级标记）；
  - 窄窗（如 80×24）下 `guard recent` 回执 `g` 滚顶后首行可见、`G` 回底；
  - 回执 argv 不含 `--config-root`，而 `execRun` 实际调用参数仍含（语义不破）；
  - set 屏组标题行存在且光标上/下移动跳过它们、Enter 命中正确动作；
  - 帮助页在 24 行视口 `g` 滚顶后 `: <command>` 尾行可达；命令表行在 80 列不丢字符（折行非截断）；
  - 键位表含 PgUp/PgDn；footer 无回归；
  - 双语全绿、`NO_COLOR` 渲染无 SGR 且布局不变。

## Out of Scope

- core / cli 的任何改动（含命令输出格式本身——`guard recent` 的 89 列定宽表保持 CLI 原样，TUI 侧折行消化）。
- 鼠标、主题配置、实时裁决流、busy 面板内 spinner（维持既有非目标/v2）。
- `exitAfterBusies` 死字段清理、统一 CLI `set set-key` 缺口。
- 回执加 root 字段在日志屏标注（v2，信息密度暂不需要）。
